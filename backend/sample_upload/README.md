# 示例上传文件说明

本目录包含可直接用于前端上传的示例文件，按复杂度分为多档，便于测试评估系统。

## 样例档位

| 目录 | 复杂度 | 用例图规模 | 适用场景 |
|------|--------|------------|----------|
| **simple/** | 简单 | 1 参与者、3 用例 | 快速验证、入门测试 |
| **medium/** | 中等 | 3 参与者、13 用例 | 常规功能测试 |
| **complex/** | 复杂 | 7 参与者、20 用例 | 多模块、多关系测试 |
| **super_complex/** | 超级复杂 | 12 参与者、50 用例、53 关系 | 极限压力、系统强度测试 |

根目录下的 `用例图.json`、`用例描述.json`、`需求文档.md` 为线上课程平台示例（中等偏上复杂度）。

**使用建议**：先用 `simple/` 验证流程，再用 `super_complex/` 测试系统在大量用例、多 include/extend 关系下的评估能力与耗时。

## 用例描述 JSON 格式

- **id**：用例唯一标识
- **name**：用例名称
- **description**：用例简述
- **actors**：参与者列表
- **preconditions** / **postconditions**：前置 / 后置条件
- **main_flow**：主事件流步骤（字符串数组）
- **alternative_flows**：异常/备选事件流数组，每项包含：
  - **name**：该分支名称
  - **condition**：触发条件（如「第5步中，验证失败」）
  - **return_to_step**：**（必填）** 返回主事件流的位置。取值为：
    - 整数 `1` ~ `主事件流步数`：该分支结束后返回到主事件流第 N 步继续执行
    - 字符串 `"end"`：该分支结束用例，不返回主流程（如流程终止、失败退出）
  - **steps**：该分支的步骤列表
- **priority** / **business_value**：可选

评估时会校验每条备选流是否包含合法的 `return_to_step`，缺失或非法会记为问题。
